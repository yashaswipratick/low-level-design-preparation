# Easy LLD Problems

1. **Library Book Catalog** - Design a system to add books, search by title/author, and mark copies as available or issued.
2. **Parking Lot (Single Floor)** - Design a parking lot that parks vehicles by slot type and supports entry/exit with fee calculation.
3. **Movie Ticket Booking (Single Screen)** - Design seat booking for one screen with seat hold, confirm, and cancel operations.
4. **Expense Splitter (Equal Split)** - Design a system to record group expenses and split them equally among members.
5. **Task Manager** - Design a personal task manager with create, update status, assign priority, and list by due date.
6. **Course Registration** - Design course enrollment where students register/drop courses with seat limits.
7. **Vending Machine** - Design a vending machine to select items, accept money, dispense change, and handle out-of-stock.
8. **Notification Preferences** - Design user notification settings with channel-level enable/disable and frequency control.
9. **Simple Rate Limiter** - Design a per-user fixed-window rate limiter for API requests.
10. **Restaurant Table Reservation** - Design reservation management with table allocation, time slots, and cancellation.
