# Hard LLD Problems

1. **Multi-Level Cache with Eviction Policies** - Design a cache supporting LRU/LFU eviction, TTL expiry, and concurrent access.
2. **Distributed Job Scheduler** - Design job submission, retries, dependency handling, worker assignment, and failure recovery.
3. **Real-Time Chat Platform** - Design conversations, message delivery states, offline sync, and group membership updates.
4. **Stock Trading Order Book** - Design order placement, matching engine, partial fills, cancellation, and trade history.
5. **Feature Flag Management System** - Design flag rollout rules, targeting, versioning, and runtime evaluation.
6. **File Storage Service** - Design file upload/download, chunking, metadata management, and access control.
7. **Ad Serving and Frequency Capping** - Design ad selection, targeting filters, pacing constraints, and impression tracking.
8. **API Gateway with Pluggable Policies** - Design request routing, authentication, throttling, and policy extension points.
9. **Workflow Orchestration Engine** - Design step execution, state transitions, compensation flow, and audit logging.
10. **Dynamic Pricing Engine** - Design pricing rules, priority resolution, experimentation support, and real-time quote generation.
