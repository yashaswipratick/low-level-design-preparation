# Day 1 - Instant + Duration + Rolling Windows

This folder contains Day 1 Java Time API exercises.

## What is included
- 5 exercise files in `submission/`
- Problem statements added in each file
- `main` test cases for quick manual verification
- Revision notes in `notes/NOTES.md`

## Package
All Java files use:
`com.lld.practice.daily_practice.day_01_instant_duration.submission`

## Compile
```bash
cd /Users/y0p03mn/preparation/src
javac com/lld/practice/day_01_instant_duration/submission/*.java
```

## Run
```bash
cd /Users/y0p03mn/preparation/src
java com.lld.practice.daily_practice.day_01_instant_duration.submission.ExcerciseOne
java com.lld.practice.daily_practice.day_01_instant_duration.submission.ExcerciseTwo
```

## How to practice
1. Open one exercise file in `submission/`.
2. Read the problem statement comment at the top.
3. Run the file and compare output with expected comments.
4. Refactor/adjust boundaries if output does not match requirements.
5. Review concepts in `notes/NOTES.md` for revision.
