# Practice Workspace Structure

Use this folder for your 10-day learning plan.

## Day-wise folders

- `day_01_instant_duration`
- `day_02_map_set`
- `day_03_comparator`
- `day_04_enum_behavior`
- `day_05_model_separation`
- `day_06_pojo_discipline`
- `day_07_requirements_assumptions`
- `day_08_pseudocode_flow`
- `day_09_interview_narration`
- `day_10_p1_attempt_2`

## Inside each day

- `submission/` -> your code and output before review
- `review/` -> my review notes and must-fix list
- `notes/` -> your learnings, mistakes, and retry checklist

## Suggested naming

- `submission/attempt-1.md`
- `submission/attempt-1-output.txt`
- `review/attempt-1-review.md`
- `notes/day-summary.md`
